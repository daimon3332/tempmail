# TempMail 功能基线

该清单是发布验收基线。新增版本不得删除既有能力或破坏上游兼容 API。

## 用户侧

- 未登录仅可访问登录页和公开 API 文档
- 用户登录、邮箱 Token 登录、邮箱创建与额度限制
- 邮箱按域名/地址搜索，邮件按时间、未读、附件筛选和排序
- MIME HTML、纯文本、原始邮件、EML 下载、已读、删除
- 发件箱、发信权限和余额
- 个人用量、Passkey、OAuth2（配置后启用）

## 管理员

- 全部邮箱、全部邮件、未知邮件、发件箱、统计和系统状态
- 用户创建、配额、月度额度、发信权限、余额、密码重置和明文查看（admin 除外）
- admin 账户禁止删除
- 角色模板（兼容能力，不是创建用户前置步骤）
- 地址设置、自动清理、数据库维护、操作日志
- IP 黑名单、Webhook、AI 提取、Telegram、OAuth2/Passkey
- 外观、站点、运行配置和 API 限流（默认每分钟 1000，可热更新）

## API

- 上游 `/api/*`、`/user_api/*`、`/admin/*`、`/telegram/*` 路径保持兼容
- 公开 `/docs/api` 和 `/api/openapi.json`
- 新增公开域名查询、健康检查、邮箱摘要、用户个人资料和管理员用户详情接口
