Tempmail 域名配置

本教程说明如何把自有域名添加到 Tempmail，并让邮箱可以接收邮件。

1. 在系统设置中添加

  1. 进入“系统设置 → 域名与新建邮箱”。
  2. 输入完整域名，例如 mail.example.com，点击“添加域名”。
  3. 勾选“默认”可作为未指定后缀时的默认域名；勾选“允许随机子域”后才能创建随机子域邮箱。
  4. 保存设置。HTTP 创建接口会立即读取新配置，SMTP 接收需要重启服务。

2. 配置 DNS

在域名 DNS 服务商处添加 MX 记录，将邮件投递到运行 Tempmail 的服务器。优先级通常设置为较低数值，例如：

  • 主机记录：mail.example.com（或你的收件子域）
  • 记录类型：MX
  • 邮件服务器：指向服务器主机名，例如 mx.example.com
  • 同时为邮件服务器主机名配置 A/AAAA 记录

如果使用 Cloudflare Email Routing，请按 Cloudflare 控制台要求配置转发，并确保 Worker 的目标地址和 INGEST_TOKEN 正确。

3. 配置发信认证

建议配置 SPF、DKIM 和 DMARC。它们能提高投递成功率，也会影响系统的垃圾邮件检查规则。

4. 重启并验证

  1. 重启 Tempmail 容器，使 SMTP 监听器加载新域名。
  2. 访问 /open_api/domains，确认域名出现在列表中。
  3. 创建一个测试邮箱，向该地址发送测试邮件。
  4. 在“邮箱与邮件”页面确认邮件进入收件箱。

常见问题

可以创建但收不到邮件：通常是 MX 未生效、服务器 25 端口未放行，或服务重启前仍使用旧域名列表。

随机子域创建失败：请先在域名列表勾选“允许随机子域”，并确认 DNS 通配符和 MX 策略覆盖该子域。
